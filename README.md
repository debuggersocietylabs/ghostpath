# Ghospath website

Static marketing, privacy, and support website for **Ghospath | Memory Game**, made for iPhone. This folder is an independent Git repository inside `ghostpath-app`.

Open `index.html` directly to preview. No install, build, third-party fonts, scripts, analytics, or cookies are required. The gameplay image is captured from the native app.

To publish with GitHub Pages, push this repository to the chosen GitHub repository, then select its `main` branch and root folder in Settings → Pages. Update the app’s marketing, privacy, and support URLs in App Store Connect after the deployment URL is verified. The local folder name does not determine the public URL. Add an App Store link once the app’s public product URL exists; the current site does not claim a public release.

Pages: `index.html`, `privacy.html`, `support.html`.
